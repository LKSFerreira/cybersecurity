## Introdução ao Python

Nesta sala (módulo), você terá uma experiência prática e aprenderá sobre a linguagem de programação de script Python. Embora a programação não seja necessária para ter sucesso em segurança, é uma ótima habilidade a se ter. Como o módulo "Scripting para Pentesters" demonstra, ser capaz de programar permite que você crie ferramentas de segurança e scripts rápidos que o ajudarão no hacking (bem como na defesa e análise).

Esta sala (módulo) lhe ensinará:

*   Variáveis
*   Laços (Loops)
*   Funções
*   Estruturas de Dados
*   Condicionais `if`
*   Arquivos

Você usará o editor de código (no lado direito) para completar exercícios e resolver desafios. Esta sala ensinará o básico, apenas o suficiente para lhe dar o conhecimento para fazer seus scripts básicos. Se você quiser usar seu próprio ambiente de desenvolvimento para programar, baixe o Python no [site oficial](https://www.python.org/downloads/); o que lhe dá um IDE (ambiente de desenvolvimento integrado) para programar.

Na programação, a **sintaxe** é importante, pois descreve a estrutura de uma linguagem de programação válida. Em termos simples, a sintaxe diz ao computador como ler o código usando regras que controlam a estrutura de símbolos, pontuação e palavras de uma linguagem de programação.
