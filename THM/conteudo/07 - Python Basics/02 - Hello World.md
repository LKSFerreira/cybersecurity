## Hello World

Para começar, vamos criar um programa simples que exibe algum texto.

```python
# Isto é um exemplo de comentário
print("Hello World")
```

Como você pode ver no bloco de código de exemplo acima, é apenas uma linha (mostrada na linha 2), e quando executamos este código, ele exibirá o texto `Hello World`. Vamos analisar isso. No exemplo, a linha 1 é um **comentário**, uma linha que começa com o símbolo de hashtag (`#`) e não é executada pelo computador. Um comentário é escrito pelo programador (você) para ajudar outras pessoas que leem o código a entender o que está acontecendo.

Podemos controlar o que é exibido na tela usando a instrução `print()`. Qualquer coisa dentro dos parênteses `()` será exibida. No entanto, como estamos imprimindo uma **string** (mais sobre tipos de dados mais adiante nesta sala), temos que colocá-la entre aspas `""`.

Por favor, note que os exemplos desta sala são para Python 3.
