## Operadores Matemáticos

Vamos agora abordar os operadores matemáticos e como eles podem ser aplicados ao Python. Como em uma calculadora, existem operações como somar, subtrair, multiplicar e dividir; usando Python, podemos codificar nossa própria calculadora; afinal, programar é apenas escrever regras para o computador seguir, dadas entradas e condições específicas. A tabela abaixo mostra as diferentes operações.

| Operador       | Sintaxe | Exemplo             |
| :------------- | :------ | :------------------ |
| Adição         | `+`     | `1 + 1 = 2`         |
| Subtração      | `-`     | `5 - 1 = 4`         |
| Multiplicação  | `*`     | `10 * 10 = 100`     |
| Divisão        | `/`     | `10 / 2 = 5`        |
| Módulo         | `%`     | `10 % 2 = 0`        |
| Exponenciação  | `**`    | `5**2 = 25` (5²)    |

Agora que conhecemos os operadores matemáticos básicos, vamos passar para os operadores de comparação; eles desempenham um papel importante no Python e serão a base quando olharmos para laços (loops) e condicionais `if`. Esses operadores são usados para avaliar a condição de um programa em um determinado estado.

| Símbolo                   | Sintaxe |
| :------------------------ | :------ |
| Maior que                 | `>`     |
| Menor que                 | `<`     |
| Igual a                   | `==`    |
| Diferente de              | `!=`    |
| Maior ou igual a          | `>=`    |
| Menor ou igual a          | `<=`    |
