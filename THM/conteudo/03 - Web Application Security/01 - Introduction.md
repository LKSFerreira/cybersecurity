## Introdução

Cada um de nós usa diferentes programas em nossos computadores. De modo geral, os programas rodam em nossos computadores, usando o poder de processamento e o armazenamento de nossos computadores. Além disso, para usar um programa, precisamos instalá-lo primeiro. E se pudéssemos usar qualquer programa sem instalação?

Uma **aplicação web** é como um "programa" que podemos usar sem instalação, desde que tenhamos um navegador web moderno padrão, como Firefox, Safari ou Chrome. Consequentemente, em vez de instalar cada programa que você precisa, você só precisa navegar até a página relacionada. A seguir, alguns exemplos de aplicações web:

*   **Webmail**, como Tutanota, Protonmail, Outlook e Gmail.
*   **Suítes de escritório online**, como Microsoft Office 365 (Word, Excel e PowerPoint), Google Drive (Docs, Sheets e Slides) e Zoho Office (Writer, Sheet e Show).
*   **Compras online**, como Amazon.com, AliExpress e Etsy.

Milhares de outros exemplos fornecem uma miríade de serviços. Outros exemplos incluem banco online, transferência de dinheiro, previsão do tempo e mídias sociais.

*Aplicação Web de Banco Online*

A ideia de uma aplicação web é que ela é um programa rodando em um **servidor** remoto. Um servidor refere-se a um sistema de computador que funciona continuamente para "servir" os clientes. Neste caso, o servidor executará um tipo específico de programa que pode ser acessado por navegadores web.

Considere uma aplicação de compras online. A aplicação web lerá os dados sobre os produtos e seus detalhes de um **servidor de banco de dados**. Um banco de dados é usado para armazenar informações de forma organizada. Exemplos incluem informações sobre produtos, clientes e faturas. Um servidor de banco de dados é responsável por muitas funções, incluindo ler, pesquisar e escrever no banco de dados. A aplicação web de compras online pode precisar acessar mais de um banco de dados, por exemplo:

*   **Banco de dados de produtos:** Este banco de dados contém detalhes sobre os produtos, como nome, imagens, especificações e preço.
*   **Banco de dados de clientes:** Contém todos os detalhes relacionados aos clientes, como nome, endereço, e-mail e número de telefone.
*   **Banco de dados de vendas:** Esperamos ver o que cada cliente comprou e como pagou neste banco de dados.

Já podemos ver a quantidade de informações armazenadas em qualquer sistema de compras online. Suponha que um invasor consiga explorar (hackear) a aplicação web e roubar o banco de dados dos clientes. Nesse caso, isso levará a uma perda significativa para a empresa e seus clientes.

A imagem abaixo mostra a busca por um item em um site de compras online. Na versão mais simples, a busca levará quatro etapas:

1.  O usuário insere o nome de um item ou palavras-chave relacionadas no campo de busca. O navegador web envia a(s) palavra(s)-chave de busca para a aplicação web de compras online.
2.  A aplicação web consulta (pesquisa) o banco de dados de produtos pelas palavras-chave enviadas.
3.  O banco de dados de produtos retorna os resultados da pesquisa correspondentes às palavras-chave fornecidas para a aplicação web.
4.  A aplicação web formata os resultados como uma página web amigável e os retorna ao usuário.

*Acessando uma aplicação web de um navegador com a infraestrutura técnica oculta*

Muitas empresas oferecem programas de **bug bounty**. Um programa de bug bounty permite que a empresa ofereça uma recompensa para qualquer pessoa que descubra uma vulnerabilidade de segurança (fraqueza) nos sistemas da empresa. A principal condição é que a vulnerabilidade encontrada esteja dentro do escopo e das regras do bug bounty. Entre muitas outras, Google, Microsoft e Facebook têm programas de bug bounty. Descobrir um bug pode render de algumas centenas de dólares a dezenas de milhares de dólares, dependendo da gravidade da vulnerabilidade, ou seja, da fraqueza que você descobriu.
