## Um Pouco de História sobre o Linux

### Onde o Linux é Usado?

É justo dizer que o Linux é muito mais intimidador de abordar do que Sistemas Operacionais (SOs) como o Windows. Ambas as variantes têm suas próprias vantagens e desvantagens. Por exemplo, o Linux é consideravelmente mais leve e você ficaria surpreso em saber que há uma boa chance de você ter usado o Linux de alguma forma ou de outra todos os dias! O Linux alimenta coisas como:

*   Sites que você visita
*   Painéis de entretenimento/controle de carros
*   Sistemas de Ponto de Venda (PoS - Point of Sale), como caixas registradoras em lojas
*   Infraestruturas críticas, como controladores de semáforos ou sensores industriais

### "Sabores" do Linux (Flavours of Linux)

O nome "Linux" é, na verdade, um termo genérico para múltiplos SOs que são baseados no UNIX (outro sistema operacional). Graças ao fato de o Linux ser de código aberto (open-source), as variantes do Linux vêm em todas as formas e tamanhos - mais adequadas para o que o sistema está sendo usado.

Por exemplo, Ubuntu e Debian são algumas das distribuições mais comuns do Linux porque são muito extensíveis. Ou seja, você pode executar o Ubuntu como um servidor (como para sites e aplicações web) ou como um desktop completo. Para esta série, usaremos o Ubuntu.

**Nota:** O Ubuntu Server pode rodar em sistemas com apenas 512MB de RAM!

Semelhante a como você tem diferentes versões do Windows (7, 8 e 10), existem muitas versões/distribuições diferentes do Linux.
