## Resumo do Módulo

Muitos atores maliciosos tendem a ofuscar seu código para evitar que seja detectado por sistemas ou compreendido por outros desenvolvedores.

A capacidade de desofuscar código é uma técnica útil que pode ser aplicada a vários cenários do mundo real. É útil em avaliações de aplicações web para determinar se um desenvolvedor usou "segurança por obscuridade" (security by obscurity) para ocultar código JavaScript contendo dados sensíveis. Também pode ser útil para defensores quando, por exemplo, tentam desofuscar o código responsável pelo site de Phishing usado em um ataque.

Neste módulo, você aprenderá o básico sobre desofuscar e decodificar código JavaScript e terá vários exercícios para praticar o que aprendeu.

Você aprenderá os seguintes tópicos:

*   Localizando código JavaScript
*   Introdução à Ofuscação de Código
*   Como Desofuscar código JavaScript
*   Como decodificar mensagens codificadas (encoded messages)
*   Análise Básica de Código
*   Enviando requisições HTTP básicas

Nosso exercício final neste módulo abrirá uma porta para muitos outros desafios e exercícios no Hack The Box!

**Requisitos**

Recomenda-se fazer o módulo [Requisições Web (Web Requests)](./0%20-%20Resumo.md) antes deste para obter uma compreensão geral de como as requisições HTTP funcionam. Se você já está familiarizado com elas, então deve ser capaz de iniciar este módulo.
