## Resumo (Summary)

Parabéns por chegar ao final do módulo de Desofuscação de JavaScript. Esperamos que agora você consiga reconhecer scripts ofuscados e desofuscá-los, decodificar sua saída e replicar suas funções.

A seguir, um resumo do que aprendemos:

1.  Primeiro, descobrimos o código fonte HTML da página web e localizamos o código JavaScript.
2.  Em seguida, aprendemos sobre várias maneiras de ofuscar código JavaScript.
3.  Depois disso, aprendemos como embelezar (beautify) e desofuscar código JavaScript minificado e ofuscado.
4.  Em seguida, analisamos o código desofuscado e sua função principal.
5.  Então, aprendemos sobre requisições HTTP e fomos capazes de replicar a função principal do código JavaScript ofuscado.
6.  Finalmente, aprendemos sobre vários métodos para codificar e decodificar strings.
