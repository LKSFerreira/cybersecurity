## Introdução

Bem-vindo ao módulo de Desofuscação de JavaScript (JavaScript Deobfuscation)!

A desofuscação de código é uma habilidade importante a ser aprendida se quisermos ser proficientes em análise de código e engenharia reversa. Durante exercícios de red team/blue team, frequentemente nos deparamos com código ofuscado que visa ocultar certas funcionalidades, como malware que utiliza código JavaScript ofuscado para recuperar seu payload principal. Sem entender o que este código está fazendo, podemos não saber exatamente qual sua função e, portanto, podemos não ser capazes de completar o exercício de red/blue team.

Neste módulo, começamos aprendendo a estrutura geral de uma página HTML e, em seguida, localizaremos código JavaScript dentro dela. Feito isso, aprenderemos o que é ofuscação, como ela é feita e onde é usada, seguindo com o aprendizado de como desofuscar tal código. Uma vez que o código esteja desofuscado, tentaremos entender seu uso geral para replicar sua funcionalidade e descobrir o que ele faz manualmente.

Os seguintes tópicos serão discutidos:

*   Localizando código JavaScript
*   Introdução à Ofuscação de Código (Code Obfuscation)
*   Como Desofuscar código JavaScript
*   Como decodificar mensagens codificadas (encoded messages)
*   Análise Básica de Código
*   Enviando requisições HTTP básicas
