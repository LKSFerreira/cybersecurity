# Módulo: Requisições Web (Web Requests)

**Detalhes do Módulo:**
*   **Nível:** 0
*   **Categoria:** Fundamental
*   **Tipo:** Geral
*   **Duração Estimada:** 4 horas
*   **Criado por:** 21y4d

Este módulo introduz o tópico de requisições web HTTP e como diferentes aplicações web as utilizam para se comunicar com seus backends.

## Resumo do Módulo

Este módulo introduz fundamentos chave que devem ser dominados para ter sucesso em segurança da informação. Compreender requisições web é essencial para entender como as aplicações web funcionam, o que é necessário antes de tentar atacar ou proteger qualquer aplicação web. Isso torna este módulo o primeiro passo em testes de penetração de aplicações web.

Este módulo apresentará esses conceitos através de duas ferramentas principais: **cURL** e as **Ferramentas de Desenvolvedor do Navegador (Browser DevTools)**. Essas ferramentas estão entre as ferramentas essenciais no arsenal de qualquer testador de penetração web, e este módulo o iniciará no caminho para dominá-las.

Além do contúdo acima, este módulo cobrirá:

*   Uma visão geral do Protocolo de Transferência de Hipertexto (HTTP)
*   Uma visão geral do Protocolo de Transferência de Hipertexto Seguro (HTTPS)
*   Requisições e respostas HTTP e seus cabeçalhos (headers)
*   Métodos HTTP e códigos de resposta
*   Métodos HTTP comuns como GET, POST, PUT e DELETE
*   Interagindo com APIs

Este módulo é dividido em seções com exercícios práticos acompanhantes para praticar cada uma das táticas e técnicas que cobrimos. O módulo termina com uma avaliação prática de habilidades para medir sua compreensão das diversas áreas temáticas.

Você pode iniciar e parar o módulo a qualquer momento e continuar de onde parou. Não há limite de tempo ou "nota", mas você deve completar todos os exercícios e a avaliação de habilidades para receber o número máximo de cubos e ter este módulo marcado como completo em quaisquer trilhas que você tenha escolhido.

À medida que você avança no módulo, verá exemplos de comandos e saídas de comandos para os vários tópicos introduzidos. Vale a pena reproduzir o máximo possível desses exemplos para reforçar ainda mais os conceitos apresentados em cada seção. Você pode fazer isso na PwnBox fornecida nas seções interativas ou em sua máquina virtual.

O módulo é classificado como "Fundamental" e pressupõe um conhecimento prático da linha de comando Linux e uma compreensão dos fundamentos de segurança da informação. Embora não seja obrigatório, recomendamos fazer estes módulos antes/juntamente com este módulo:
